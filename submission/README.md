# Submitting to the directories

1. Publish the privacy policy addition.
2. Test with the reviewer account as a custom connector in Claude and a custom MCP server in ChatGPT, using `test-prompts.md`.

4. Submit the plugin with `claude-plugin.md`.
5. Submit to ChatGPT with `chatgpt.md`.
